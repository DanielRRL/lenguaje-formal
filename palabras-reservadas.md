# Palabras reservadas

| Palabra | Significado | Categoría |
|---|---|---|
| IF | Indica que se evaluará una condición | Palabra clave |
| THEN | Indica la acción que se ejecutará si se cumple la condición | Palabra clave |
| AND | Une dos condiciones que deben cumplirse | Operador lógico |
| OR | Permite establecer una alternativa entre condiciones | Operador lógico |
| TRUE | Representa un valor verdadero | Literal booleano |
| FALSE | Representa un valor falso | Literal booleano |

## Operadores relacionales

| Operador | Significado |
|---|---|
| > | Mayor que |
| < | Menor que |
| >= | Mayor o igual que |
| <= | Menor o igual que |
| == | Igual que |
| = | asignación |
