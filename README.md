# Lenguaje de reglas para dispositivos móviles

## Integrantes

- REINA
- ALMEIDA
- AMORTEGUI
- ARIAS

## Descripción del proyecto

Este proyecto consiste en el diseño de un lenguaje de reglas orientado a
dispositivos móviles.

El lenguaje permitirá definir condiciones relacionadas con el funcionamiento
de un celular, como batería, temperatura, almacenamiento, brillo, volumen,
señal, memoria RAM y conexión a internet.

Dependiendo de las condiciones establecidas, el sistema podrá ejecutar
acciones determinadas, como activar el ahorro de energía, mostrar alertas,
reducir el brillo o cerrar aplicaciones.

El proyecto busca aplicar conceptos de **Lenguajes Formales**, mediante la
definición de reglas, variables, tipos de datos, operadores y palabras
reservadas que posteriormente podrán ser procesados por un programa.
